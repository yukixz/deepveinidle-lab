# 战斗公式

查看装备、角色属性、战斗、经验、补给与掉落的计算方式，了解不同加成如何影响战斗表现。

适用游戏版本：**1.0.1225**。

## 通用记号

- `floor(x)`：向下取整。
- `ceil(x)`：向上取整。
- `round(x)`：取最近的整数；恰好位于两个整数中间时向较大值取整，例如 `round(2.5) = 3`、`round(-2.5) = -2`。
- 百分比以小数代入，例如 `25% = 0.25`。
- 一游戏刻为 `0.6 秒`。
- 当前攻击技能指武器对应的近战、远程或魔法技能。
- 下文的精通加成以百分比代入。例如命中精通 10 级，每级增加 1%，公式中代入 `0.10`。
- 药水强度：未生效为 `0`；普通、罕见、稀有、史诗、传说依次为 `1 / 1.3 / 1.6 / 2.2 / 3`。不同药水分别取自身强度。
- 等级提升或增益到期后，后续战斗按变化后的属性计算。

## 一、装备

### 1. 品质与强化后的整数属性

适用于装备的命中、力量、防御：

```text
品质后属性 = round(基础属性 × 品质倍率)
强化倍率 = 1 + 0.06 × min(20, 强化等级) + 0.10 × max(0, 强化等级 - 20)
最终属性 = round(品质后属性 × 强化倍率)
```

| 品质 | 普通 | 罕见 | 稀有 | 史诗 | 传说 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 品质倍率 | 1 | 1.3 | 1.6 | 2.2 | 3 |

两次取整分别执行，武器的基础攻击间隔保持其固定值。未完成地牢装备先按原始已投入遗物规则计算品质属性，再乘强化倍率。

### 2. 护符幸运

```text
护符幸运 = 基础幸运 × 品质倍率 × 强化倍率
```

护符幸运保留小数，不像命中、力量和防御那样进行两次整数取整。

### 3. 流派适配与装备限制

- 护甲与副手需匹配武器流派。命中、力量、防御均汇总生效装备的属性。
- 当前攻击流派由实际武器决定；空手为近战。
- 双手武器不能同时使用盾牌，不能把两者属性一起计入角色。
- 装备需要满足对应的技能等级要求。

### 4. 坐骑移动加成

```text
坐骑移速加成 = 基础加成 × 坐骑品质倍率 × (1 + 0.15 × 强化等级)
```

当前坐骑基础加成为 `12%`。

| 品质 | 普通 | 罕见 | 稀有 | 史诗 | 传说 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 坐骑品质倍率 | 1 | 1.5 | 2.25 | 3.5 | 5 |

坐骑采用独立倍率，不能套用普通装备属性倍率。

## 二、角色属性

### 1. 装备属性合计

```text
装备力量 = 按流派适配规则汇总各装备力量
装备命中 = 按流派适配规则汇总各装备命中
装备防御 = 各装备防御之和
```

先计算每件装备的品质与强化属性，再进行汇总。

### 2. 命中值

```text
药水命中加成 = round(10 × 战士药水强度)
命中值 = round((10 + 当前攻击技能等级 + 装备命中 + 药水命中加成)
              × (1 + 命中精通))
```

### 3. 闪避值与最大生命

```text
闪避值 = 10 + 防御技能等级 + 装备防御
最大生命 = floor(生命值技能等级 × (1 + 生命精通))
```

### 4. 最大伤害

```text
基础最大伤害 = 1 + floor((当前攻击技能等级 + 装备力量) / 武器系数)

伤害倍率 = (1 + 0.10 × 战士药水强度 + 饱食伤害加成)
           × (1 + 家园流派伤害加成)
           × (1 + 最大伤害精通) × 地牢套装倍率

最终最大伤害 = 伤害倍率 > 1 时，ceil(基础最大伤害 × 伤害倍率)
               否则，基础最大伤害
```

| 武器 | 伤害系数 |
| --- | ---: |
| 空手、普通近战武器、短弓 | 8 |
| 法杖 | 4.5 |
| 大剑 | 6 |
| 长弓 | 5 |

饱食生效时伤害加成为 `25%`，否则为 `0`。战士药水与饱食先相加，再乘家园、精通和套装倍率。头部、胸部、腿部、武器中至少两件属于同一阶地牢套装时，按最高满足条件的阶数取最大伤害加成 5.5%、7.5% 或 9.5%。

对应流派的家园伤害设施须已放置，每级增加 `0.5%`。当前建筑最多 50 级，因此最高加成为 `25%`；原始公式仍保留单设施 `50%` 的计算封顶。

### 5. 平均攻击间隔

```text
每刻攻击进度增量 = round(1000 × (1 + 0.20 × 急速药水强度))
平均攻击间隔（刻）= 武器基础间隔（刻）× 1000 / 每刻攻击进度增量
平均攻击间隔（秒）= 平均攻击间隔（刻）× 0.6
```

空手基础间隔为 `5 刻`；装备武器后读取武器基础间隔。平均间隔用于长期速率解释，实际攻击在整数游戏刻触发。

### 6. 相关精通

| 精通 | 每级加成 |
| --- | ---: |
| 命中 | 1% |
| 最大生命 | 0.5% |
| 最大伤害 | 0.5% |
| 经验 | 0.5% |
| 稀有发现 | 0.5% |
| 移动速度 | 0.5% |

## 三、战斗判定

### 1. 双方命中率

```text
我方命中率 = 我方命中值 / (我方命中值 + 10 + 怪物防御 × 目标防御倍率)
敌方命中率 = (10 + 怪物攻击) / (10 + 怪物攻击 + 我方闪避值)
```

| 武器 | 目标防御倍率 |
| --- | ---: |
| 空手、普通近战武器、短弓 | 1 |
| 法杖 | 0.5 |
| 大剑 | 0.75 |
| 长弓 | 0.9 |

固定的 `10` 不受穿甲影响。普通怪物防御影响命中率，不再扣减我方最大伤害。

### 2. 单次伤害与减伤

```text
武器间隔系数 = min(6, max(3, 武器基础攻击间隔刻数))
我方伤害下限 = max(1, floor(最终最大伤害 × 武器间隔系数 / 15))
我方命中后伤害 = 伤害下限～最终最大伤害之间的原始随机整数
敌方原始伤害 = 1～怪物最大伤害之间的随机整数
敌方命中后伤害 = max(1, floor(敌方原始伤害 × (1 - 减伤率)))
```

未命中时伤害为 `0`。当前普通战斗无暴击。

作物增益生效时减伤率为 `20%`，否则为 `0`。装备防御通过闪避减少受击，不直接扣减单次伤害。

### 3. 理论 DPS

```text
每次攻击尝试的期望伤害 = 我方命中率 × (最终最大伤害 + 1) / 2
理论 DPS = 每次攻击尝试的期望伤害 / 平均攻击间隔（秒）
```

当伤害下限大于 1 时，原始引擎调整区间内的抽样分布，使平均伤害仍约为 (最大伤害 + 1) / 2。理论输出按持续攻击估算，实际结果还取决于寻敌、移动、补给、死亡、过量伤害和战斗切换。

## 四、战斗经验

### 1. 经验倍率

```text
共用经验倍率 = 1 + 世界窗口经验加成
                 + 0.10 × 经验药水强度
                 + 祝福经验加成
                 + 公会经验加成
                 + 热门战斗经验加成
                 + 经验精通

攻击技能倍率 = 共用经验倍率 + 家园战斗经验加成 + 对应技能经验加成
防御技能倍率 = 共用经验倍率 + 家园战斗经验加成 + 防御技能经验加成
生命技能倍率 = 共用经验倍率 + 家园战斗经验加成
```

祝福经验加成为 `5%`，热门战斗经验加成为 `20%`；未生效时为 `0`。

家园战斗经验设施每级增加 `1%`；对应技能经验设施每级增加 `1%`，均须已放置。上述经验加成相加，不逐项相乘。

### 2. 每只怪物的经验池

```text
攻击技能经验池 = round(怪物经验 × 攻击技能倍率)
防御技能经验池 = round(max(1, floor(怪物经验 / 3)) × 防御技能倍率)
生命技能经验池 = round(max(1, floor(怪物经验 / 3)) × 生命技能倍率)
```

攻击技能经验发放给当前武器对应技能。

### 3. 按伤害发放经验

对每项技能分别计算，设怪物最大生命为 H，攻击前后剩余生命分别为 h前、h后：

```text
本次技能经验 = round(技能经验池 × (H - max(0, h后)) / H)
               - round(技能经验池 × (H - max(0, h前)) / H)
```

经验随伤害发放，不必等到击杀；过量伤害不会额外增加经验。经验池按该次攻击时的角色状态计算，战斗中升级或增益变化可能改变后续攻击的经验池。

## 五、食物、增益与移动

### 1. 治疗量

```text
单份食物治疗量 = floor(该品质食物治疗值
                      × (1 + 0.025 × 饮食特权等级 + 0.25 × 滋养药水强度))
实际恢复生命 = min(单份食物治疗量, 最大生命 - 当前生命)
```

食物治疗值读取对应品质物品，不能再重复乘一次品质倍率。

### 2. 自动进食

角色存活、启用进食且有可用食物时，在战斗攻击事件后检查：

```text
当前生命 ≤ 最大生命 × 进食阈值
```

满足条件时执行进食。没有食物时的回仓、泉水恢复属于路线与补给流程，不用单一治疗公式替代。

### 3. 饱食与作物增益持续时间

| 食物品质 | 普通 | 罕见 | 稀有 | 史诗 | 传说 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 饱食持续时间 | 无 | 120 秒 | 10 分钟 | 3 小时 | 24 小时 |
| 作物持续时间倍率 | 1 | 2 | 5 | 12 | 30 |

作物基础持续时间由该作物种植配方的所需等级计算。设该等级为 L，相关作物配方最高所需等级为 L最高：

```text
等级比例 = L最高 > 1 时，(L - 1) / (L最高 - 1)；否则为 0
基础持续时间（刻）= round((100 + 900 × 等级比例) / 100) × 100
作物减伤持续时间（秒）= 基础持续时间（刻）× 品质持续时间倍率 × 0.6
```

仅可食用作物提供作物减伤增益。

同类增益可续期：

```text
新到期时间 = max(当前时间, 原到期时间) + 本份持续时间
```

饱食提供伤害加成，作物增益提供减伤；二者分别维护到期时间。

### 4. 最终移动速度

```text
坐骑速度 = 1000 + round(坐骑移速加成 × 1000)
最终移动速度 = round(坐骑速度
                    × (1 + 0.20 × 疾行药水强度)
                    × (1 + 移动精通))
```

无坐骑时坐骑移速加成为 `0`，速度基准为 `1000`。具体移动耗时仍由路径与逐刻移动进度决定。

## 六、金币与掉落

本章概率、期望使用均匀随机判定模型，不表示固定周期必定获得掉落。普通掉落、额外掉落、宠物、虚空碎片分别判定，可以同时获得。

### 1. 金币与金币期望

```text
金币倍率 = 1 + 0.25 × 深渊药水强度
单次金币 = floor(怪物金币闭区间内的随机整数 × 金币倍率)
```

金币期望是各种可能金币数的加权平均。若金币区间为 [a, b]，令：

```text
N = b - a + 1
q = floor(2^32 / N)
r = 2^32 mod N

偏移 i 的权重 = (q + (i < r 时为 1，否则为 0)) / 2^32
金币期望 = 对 i = 0～N-1 求和：floor((a + i) × 金币倍率) × 偏移 i 的权重
```

每个可能金币数须先应用加成并向下取整，不能直接用区间平均数乘倍率。上式保留了游戏随机取值产生的微小权重差异。

### 2. 战斗稀有倍率

```text
战斗稀有倍率 = 1 + 世界窗口稀有加成
                 + 0.25 × 猎手药水强度
                 + 祝福稀有加成
                 + 热门战斗稀有加成
                 + 稀有发现精通
```

祝福稀有加成为 `10%`，热门战斗稀有加成为 `25%`，未生效时为 `0`。

### 3. 普通掉落品质

```text
普通掉落品质倍率 K = (1 + 护符幸运) × (战斗稀有倍率 + 家园稀有加成)
```

幸运神龛须已放置，每级增加 `0.5%` 家园稀有加成。

| 品质门槛 | 基础累计阈值 |
| --- | ---: |
| 罕见及以上 | 1/40 |
| 稀有及以上 | 1/400 |
| 史诗及以上 | 1/8000 |
| 传说 | 1/150000 |

各阈值先乘 K，并裁剪至 [0, 1]，记为 T罕见、T稀有、T史诗、T传说：

```text
普通概率 = 1 - T罕见
罕见概率 = T罕见 - T稀有
稀有概率 = T稀有 - T史诗
史诗概率 = T史诗 - T传说
传说概率 = T传说

每次击杀某品质掉落期望数量 = 怪物普通掉落概率 × 该品质概率
```

怪物未单独指定普通掉落概率时按 `1` 处理。累计阈值不是各品质最终独立概率，不能直接作为五种品质数量相加。

### 4. 额外掉落

```text
额外掉落概率 = min(1, 基础概率 × (1 + 护符幸运) × (战斗稀有倍率 + 家园稀有加成))
```

包含已放置幸运神龛的加成；成功时获得该怪物指定的额外物品。

### 5. 战斗宠物

```text
每次击杀的宠物概率 = 1/500000
```

宠物种类由怪物决定，不受护符幸运、猎手药水、神龛或稀有发现精通影响。

### 6. 虚空碎片

```text
触发概率 = min(0.20, 0.08 + 0.0013 × 怪物等级)
成功时数量 = 1 + floor(怪物等级 / 30)
每次击杀期望数量 = 触发概率 × 成功时数量
```

不受上述稀有加成影响。

### 7. 坐骑掉落

```text
每次攻击尝试的坐骑概率 = min(1, max(0, 武器基础间隔（刻）) / 300000)
```

包括未命中的攻击尝试；铁人模式为 `0`。使用未经急速修正的武器基础间隔，不能代入平均攻击间隔。

| 品质门槛 | 坐骑基础累计阈值 |
| --- | ---: |
| 罕见及以上 | 25% |
| 稀有及以上 | 5% |
| 史诗及以上 | 1% |
| 传说 | 0.2% |

坐骑品质阈值仅乘 `(1 + 护符幸运)`，再按普通掉落相同方法裁剪、相减，不计猎手药水、神龛等加成。

```text
每次攻击尝试某品质坐骑期望数量 = 坐骑触发概率 × 该品质概率
```

## 七、世界首领：理论输出

```text
首领战斗中的我方最大伤害 = max(1, round(角色最大伤害 × 流派倍率))
流派倍率 = 弱点流派时 1.3，否则 0.85

我方命中率 = 我方命中值 / (我方命中值 + 10 + 首领基础防御 × 目标防御倍率)
敌方命中率 = (10 + 首领基础攻击) / (10 + 首领基础攻击 + 我方闪避值)
敌方最大伤害 = max(1, floor(首领基础最大伤害 × (1 - 减伤率)))

理论 DPS = 我方命中率 × (首领战斗中的我方最大伤害 + 1) / 2
           / 平均攻击间隔（秒）
```

此处使用客户端基础属性估算持续攻击的理论输出，不计移动、补给、死亡、增益到期和战斗提前结束。实际团战规则尚未完整核验，理论 DPS 不代表实际团战输出，也不能用于推导实际击杀时间或奖励。
