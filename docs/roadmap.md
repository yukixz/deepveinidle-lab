# 后续范围

以下内容不属于当前版本已完成功能，实施前应细化需求与验收标准。

- 精通自动分配后续可增加强化成本及多活动权重目标；战斗／采集／制造经验目标已实现，未实现目标不显示界面选项，现行搜索规则见[精通页面](pages/mastery.md#计算最优分配方案)。
- 在现有可配置时长连续模拟基础上，研究更长周期、有限时增益续用和连续任务场景；当前手动启用增益仍全程有效。
- 增加 A/B 配装比较、击杀时间分布与多随机种子风险分析，展示长期利润估计误差；不将面板 DPS 直接换算为挂机利润。
- 核验世界首领服务端动态机制，再设计实际团战模拟、总血量、排名与击杀时间估算。
- 炼金生产、强化委托与组队地牢分别设计计算范围和验收条件。
- 增加公开资源版本检测，更新仍须经过差异审阅与回归验证。
- 强化增加动态等级、有限库存、任意报价保本概率输入与自动优化核心策略；需另行设计与验证，现行计算边界见[强化页面](pages/enhancement.md)。

范围确认、设计与实现流程见 [AGENTS.md](../AGENTS.md)。当前功能规则从 [DESIGN.md](../DESIGN.md) 查阅。
