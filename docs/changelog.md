# 变更日志

## 未发布

- **物品价格**：战斗、采集、制造和强化可分别设置估值来源。战斗、采集和制造可选择缺价处理。全局行情与锁定入口移至各页的「物品价格」小节，更新行情时保留已有锁定价。技能首领的模拟配置也可选择材料价格来源，用于直购和自制采购额。感谢 YuXiaohuann 对价格设置的贡献。 [PR #2](https://github.com/yukixz/deepveinidle-lab/pull/2)
- **模拟条件**：战斗、采集和制造共用模拟时长输入。热门加成默认按当前时间，已有选择继续保留。
- **配置面板**：角色配置和模拟配置可独立折叠、重置。清空角色配置保留模拟条件与价格选项，模拟配置重置恢复本面板的默认值。战斗页的两块配置面板在窄屏下与结果列对齐，折叠后宽度保持一致。
