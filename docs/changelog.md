# 变更日志

## 1.15.0

- **共用游戏资源**。各页统一使用游戏 1.0.1228。战斗沿用原始逐刻模拟，零遗物旧装备恢复为同品质、同强化的来源装备。
- **强化**。按物品上限计算，更新陨铁费用和保护规则。高强化计入保底、强化精华及可选巨像核心，支持平均投入和保本费用。
- **采集、制造与精通**。采集计入地牢钥匙、寻钥者耳环和驮夫大衣。制造新增烧瓶与地牢补给，精通方案纳入新版数据，热门预报支持偷窃稀有加成。
- **技能首领与行情**。投喂加入饲首者耳环、补剂和首领精华。全局行情识别新版物品，区分市场交易和商人收购。

## 1.14.0

- **战斗**：普通怪物模拟同步游戏 1.0.1225 的原始伤害抽样与补给路线。装备支持地牢套装、耳环、遗物进度和分物品强化上限，跨流派护甲与副手在计算时排除。

## 1.13.0

- **物品价格**：战斗、采集、制造和强化可分别设置估值来源。战斗、采集和制造可选择缺价处理。技能首领的模拟配置也可选择材料价格来源，用于直购和自制采购额。五页统一采用左标签、右下拉框的布局。全局行情与锁定入口移至各页的「物品价格」小节，更新行情时保留已有锁定价。感谢 YuXiaohuann 对价格设置的贡献。 [PR #2](https://github.com/yukixz/deepveinidle-lab/pull/2)
- **模拟条件**：战斗、采集和制造共用模拟时长输入。热门加成默认按当前时间，已有选择继续保留。
- **配置面板**：角色配置和模拟配置可独立折叠、重置。清空角色配置保留模拟条件与价格选项，模拟配置重置恢复本面板的默认值。战斗页的两块配置面板在窄屏下与结果列对齐，折叠后宽度保持一致。
