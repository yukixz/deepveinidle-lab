# 投喂性价比

从主导航「技能首领」打开 `/boss-feed`，按期望 100 箱比较熔炉之心、海妖、菌群、枯萎之花和围城的投喂物品。左侧「角色配置」先显示简介和「导入游戏角色」，随后为首领与角色设置。左栏下方另有独立、默认展开且可折叠的「模拟配置」。右侧「生效角色配置」沿用采集页的标题样式，右侧绿色标签显示所选首领。属性卡片固定为两行，每个技能一行，突出技能等级和各项属性数值。窄屏卡片沿用采集页的 128px 最小宽度，宽度不足时两行一起横向滚动。下方为带有「每100箱」标记的「投喂物品性价比」表格。页面支持中英文，桌面和窄屏沿用[共用布局](../shared.md#22-语言布局与持久化)。

## 配置与比较

- 五个首领使用采集页同款两列切换按钮，各有对应图标。左栏提供角色导入、手动配置与独立保存提示。
- 「时间金币参数」放在左栏首领选择下方，用于将时间成本换算成金币成本。单位为 M 金币／天，默认 0，五个首领共用。
- 生效属性按技能显示「采集速度加成」或「制造速度加成」，采用采集页和制造页的百分比格式。农耕的采集和制造速度不同时分别显示。
- 角色配置中，技能直接填写等级，精通沿用制造页的百分比加成输入。工具与装备沿用制造页的[共用布局](../shared.md#22-语言布局与持久化)，效果写在下方。药水显示所选品质的加成，家园显示每级及当前加成。特权每项一行，说明沿用制造页文案。「其它」仅在世界增益经验下方显示「导入捕获时生效的世界增益，整个模拟周期保持生效。」生活衣分别显示单件与套装合计的技能经验和投喂贡献。
- 「投喂物品性价比」的桌面筛选第一行是搜索、技能、分类和品质，沿用制造页样式。技能单选，提供「全部技能」（默认）及当前首领的两个技能。分类和路线按所选投喂技能筛选，切换技能后保留仍适用的分类，否则回到「全部分类」。品质可多选，默认普通与罕见。第二行是自制策略下拉框、市场卖单量，以及「只看等级符合」「使用经验炉火」「自制计算时间成本」三个勾选框。策略默认「直购+自制」，还可选「仅直购」或「仅自制」。三个勾选框默认均勾选。窄屏按可用宽度换行。
- 筛选和开关按首领独立保存在当前浏览器。经验炉火只影响投喂经验。取消自制时间成本可比较代工场景。清空品质选择时显示空结果。
- 角色表单覆盖当前配对技能的等级、工具、家园及各自精通，并共用副手、坐骑、生活衣、药水、特权和经验增益。可手动填写，或使用[共用角色导入与自动更新](../shared.md#导入游戏角色与自动更新)。导入一次写入所有首领涉及的技能等级与精通，以及选中首领的工具、家园和共用属性。选择其他首领时立即使用对应的已保存等级与精通，并保留导入时间。工具和家园的缺失提示仅在本次导入的首领显示，已填值按对应字段的导入规则保留。页面存档仅保存参与计算的配置和来源时间。「清空配置」恢复默认角色并清除导入状态，保留首领比较设置与自动更新开关。
- 路线表显示完整品质物品、投喂技能、备料方式、交付量、金币成本、总耗时和两项技能经验。默认金币成本升序，未知值排序在末尾。搜索支持中英文物品名，挂单量必须严格大于阈值，留空显示全部供应状态。
- 路线筛选和排序后按每页 10 条显示。多页时，表格底部居中排列首页、上一页、当前页码、下一页和末页。按钮按内容取宽，采用统一内边距和最大宽度，页码保持单行。切换首领、筛选或排序时回到第一页。展开详情跟随所属路线显示。
- 结果下方沿用采集和制造页的说明样式，简述工时估算、自制范围和金币成本口径。
- 行详情列出单件贡献和经验、预期箱数、投喂与补料耗时、制造用时和经验、采购原料、价格、限定供应量及收入损失。投喂秒数由模型估算。等级不足或资料缺失时显示对应原因。

## 行情

「模拟配置」的「物品价格」小节包含「材料」和「全局行情与锁定」。五个首领共用同一材料价格来源，直购投喂物品与自制直接原料均按完整品质 ID 取价。来源可选成交价（7天）、卖单、买单、商人价和无价值，默认成交价（7天）。选无价值时按 0 估值，其余来源优先使用有效全局锁定价。缺价继续留空。全局弹窗用于查看报价、设价、锁定和更新行情。「重置设置」只恢复材料价格来源，角色清空及导入保留该选项。切换来源和重置复用工时估算。相关物品的有效单价或卖单量变化时，只刷新估价。时间金币参数和自制时间成本开关变化时，从已估算的工时换算金币成本。配置角色、切换首领或调整经验炉火时重新估算路线。未定价时相关采购额留空，仍可查看数量、耗时和经验。

直购供应量为该品质的卖单数量。单层制造供应量由直接原料的卖单数量分别除以每件平均用量，取其中最小值并向下取整。零挂单保留为 0，缺失供应量显示为空，启用数量筛选时排除未知项。

## 计算规则

投喂计入饲首者耳环、饲首者补剂和技能套装的原始点数贡献。启用补剂时，按投喂期间持续生效估算，每满或不足一小时计一瓶。采购明细与成本计入补剂，市场供应量继续按投喂物及其直接原料计算。首领精华可投入任意栏，每个提供 0.68 基础点，无投喂经验。每个首领显示一条直购路线，使用原始专用投喂速率并沿用可堆叠物品的补料估算。驮夫大衣的背包容量及移动加成进入物流。开箱核心碎片的原始基础概率为 3%，本页目标仍按期望 100 箱的投喂点数计算。验收覆盖装备及补剂导入、加成叠加、首领精华和缺价处理。

游戏判定一整件可交付物品的资格、贡献和经验，按规则应用印记、套装、人物属性与炉火。交付量向上取整为 `100 × 单箱门槛 / 每件贡献`。经验按技能累计投喂和备料两部分。直接购买备料工时为 0。自制仅计算该物品的单层配方，按工时模型估计产量、直接原料和挂单可支持的成品数量。

普通投喂物的投喂与备料耗时使用 `@dvi-lab/work-time` 0.3.0。规则与主模拟共用 Lab 的公开客户端快照，由同一[提取流程](../technical.md#62-原始代码复用)生成。投喂耗时含持续投喂与补料物流，规则或路线缺失时显示其余已知结果。特殊工具免耗按常规配方估算时，详情会给出提示。

总耗时等于备料加投喂。金币成本等于采购额加按工时折算的主业收入损失。关闭自制时间成本时，仅按投喂时间折算主业收入。主业收入为 0 时，已知的采购额可单独用于金币成本比较。

## 验收

验证价格来源切换、五首领共用、刷新和面板重置范围，并核对工时与已有设置。覆盖五个首领的候选、不同品质及技能门槛，核对模型投喂耗时、采购和自制路线、炉火、时间成本开关及两个技能的经验。用合成数据验证共用行情更新、全局手动定价、缺价、零价格与零挂单。验证技能联动分类和路线、按首领恢复技能与分类、双语搜索与排序、分页及筛选后回到第一页、单次导入后的五个首领等级切换及精通取值、桌面分栏、390px 下属性卡片横向滚动及直接访问路由。
