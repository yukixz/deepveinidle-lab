# 战斗页面

精通页的“计算最优分配方案”可以只读当前战斗配置快照，对单个普通怪物优化战斗总收入；不修改本页配置或触发本页模拟。其预算、种子、价格冻结和近似搜索规则见[精通页面](mastery.md#计算最优分配方案)。

### 3.1 页面结构

左侧角色配置和模拟配置，右侧依次为角色属性、敌人利润列表；导航与响应式规则见[共用页面规则](../shared.md)。

### 3.2 导入配置

角色导入区域提供默认关闭的“自动更新角色配置”，使用[共用角色自动更新](../shared.md#导入游戏角色与自动更新)；更新范围沿用本页手动角色导入，不新增库存自动更新。

- 战斗页导入区域仅提供“导入配置”；无分类筛选及其保存偏好。导入配置覆盖全部受支持的角色配置，仍使用手动模拟规则，自动保存；先恢复默认配置，再覆盖成功导入的字段；食物例外见下文。保留“模拟配置”的敌人选择、模拟时长、热门加成，“显示全部装备”先关闭再按导入装备判断。
- 导入配置复用现有九类映射，但用户不能筛选：精确经验换算等级；装备品质及强化；食物策略；当前药水品质桶；已放置家园；精通；公会、祝福、捕获时全部有效世界窗口的经验与稀有度；补给与三类战斗天赋。非食物字段缺失、无效或无法映射时恢复默认并提示：技能为近战/远程/魔法/防御 1、生命 10，装备和坐骑为空且品质/强化归零，风格默认近战，药水关闭，家园/精通/天赋为 0，公会经验、世界增益经验与稀有度 0%，祝福和铁人关闭，仓库自动，所属公会为空；未参与导入的模拟配置恢复各自默认值。成功导入武器后风格随武器确定。

  自动食物选择遵循原始仓库锁定规则，按完整物品编号匹配 `bankLocked`；角色开启「仍可使用锁定物品」（`lockedUsable: true`）时可选用锁定食物，旧捕获缺此开关按关闭处理。自动选择时缺少锁定列表的旧捕获或非法列表保留原食物选择并明确提示；缺字段提示更新脚本并刷新游戏重新捕获。指定食物与仅喷泉策略不依赖此列表；合成模拟仍用无限未锁定食物库存，不新增锁定设置。验收覆盖锁定最高／最低品质、全部锁定、允许使用锁定食物、旧捕获、非法列表及只读捕获往返。

  食物品种/品质、策略、阈值、品质上限、携带量、伤害食物增益与作物减伤仅覆盖成功导入的字段，其余保留原值。整体导入失败保留全部原配置，不先写入默认值。该规则同时用于调试页文件导入战斗配置，不影响强化导入。验收覆盖完整/部分数据、无效字段回退、全部食物例外、跨流派配置提示、保存往返和失败原子性。
- 自动食物配置导入：优先好食物/差食物时，从捕获的仓库按原始选食函数选出当前首选食物，导入品种和品质，保留自动策略；仅泉水成功导入，不要求选出食物。仓库缺失、条目异常、品质上限无效或无合格食物时保留原食物并说明原因，有效的其他食物字段仍独立导入。指定食物不依赖库存。此映射仅用于配置导入；模拟仍为单种食物无限补给，不还原库存耗尽后的切换。验收覆盖两种排序、品质上限、同治疗量编号排序、空/异常库存、仅泉水、指定食物及双语提示。
- 导入区域不展示刷新读取提示或配置导入说明段落；手动假设记录于本设计文档（3.3.1、3.3.5）。角色配置始终可编辑，修改后按现有规则保存。
- 共用导入交互见 [共用导入协议](../technical.md#61-角色导入组件与-userscript-协议)。配置导入成功显示脚本捕获时间。切换流派时应用已导入的[对应技能精通](../shared.md#导入精通页)。

  部分字段导入失败按分类去重提示：食物单独首行提示“【食物】部分配置未导入，已保留原值，请手动检查”，并在该行补充仓库缺失、库存异常、品质上限无效或无可用食物的具体原因；其他失败分类汇总为下一行“【技能、装备等分类名称】导入失败，请手动配置”，实际名称以“、”分隔，无对应失败时省略该行。英文同步采用相同分组和换行；战斗页与调试页文件导入共用，不显示内部字段键。保存失败仍单独提示。

### 3.3 角色与模拟配置

本节描述手动配置及“导入配置”的编辑与保存规则。

菜单按“技能”“装备”“食物”“药水”“家园”“精通”“天赋”“其它”排列；“其它”（英文 Other）为一个折叠菜单，内部按公会与祝福、补给顺序连续展示，无独立子菜单或分组小标题；“其它”内所有配置统一采用左侧名称、右侧控件的双列布局，数值输入和下拉框使用相同宽度，开关位于右侧，前四项名称为“公会经验 (%)”“世界增益经验 (%)”“世界增益稀有发现 (%)”“矿脉祝福”（英文 Guild XP (%), World buff XP (%), World buff rare finds (%), Vein blessing），祝福效果在开关下方说明；长名称自然换行。“模拟配置”单独置于角色配置面板下方，内容见 [战斗模拟配置](combat.md#336-模拟配置)。不再生成“一起蛐蛐撒库拉”隐藏菜单。菜单沿用共用折叠状态保留规则。

#### 3.3.1 战斗风格与技能

- 提供近战、远程、魔法选择，当前风格及对应攻击技能高亮，风格保存到本地。
- 所有战斗技能仅编辑等级，初始经验取所填等级的最低经验，级内进度为 0，无累计经验输入；忽略旧手动存档中的对应覆盖值。模拟中仍正常获得经验和升级。
- 切换风格保留技能等级、通用装备与增益。默认清除不匹配装备，开启“显示全部装备”时保留原护甲与副手。远程或魔法无武器时选择该风格基础武器，避免空手导致计算风格错误。
- 技能等级范围取原游戏等级表，当前为 1–241。
- 首次打开提供 85 级远程示例配置；风格切换本身不重置为示例配装。支持清空配置。

#### 3.3.2 装备

- 战斗装备目录使用共用的游戏 1.0.1228 公开客户端，含已开放的地牢装备与耳环槽。强化值按物品各自上限解码、编辑和导入，常规战斗装备和坐骑至 +20、地牢套装至 +40、地牢首饰至 +25。超限旧手动存档收敛到对应上限，导入超限字段按配置警告处理。未完成地牢装备保留正数遗物进度并按原始规则计算属性。零遗物的旧配置与角色快照还原为来源装备，保留品质及强化等级。手动选择未完成装备从一枚遗物起算。验收覆盖零遗物还原、正数进度及三流派普通战斗逐刻对照。旧快照缺少耳环时视为该槽为空。普通战斗应用原始通用属性和套装加成，地牢专属效果与组队地牢模拟暂不提供。

技能副手及技能套装可随角色装备导入；套装只提供对应非战斗技能经验，不增加战斗属性。套装无品质与强化，相关控件禁用，旧异常设置规范化为普通 +0。战斗预设排除技能副手和套装，保持原有战斗配装。

- 支持武器、副手、头部、胸部、腿部、戒指、护符、耳环和坐骑九个部位。
- 装备清单从原游戏数据生成，默认显示当前风格和通用装备。武器列表随当前风格筛选。
- 每件装备独立设置普通、罕见、稀有、史诗、传说品质，强化项以上游物品上限为准。
- 坐骑清单取原始工具定义中的 mount，当前为马（328）；支持空、五种品质与 +0 至 +20 强化，无技能等级门槛，切换风格保留。旧存档与示例配置默认无坐骑。显示坐骑自身移动速度加成，不显示战斗属性。
- 当前快照保留已核验的原始装备整数属性：法杖／魔典命中与力量提高约 25%，近战六档盾牌防御提高约 40%；陨铁剑／大剑穿戴要求为近战 75（制造要求仍为 85）。新增龙弦短弓／长弓与余烬木法杖（对应技能 95），渊织兜帽／长袍／裙／魔典（魔法 99），均支持五品质、强化、角色导入与保存往返。装备品质／强化同行网格允许品质列收缩，强化输入可收缩，390px 双语展开装备时不得撑宽页面。
- 等级不足的装备仍计入战斗属性与模拟，并按部位提示“等级不足，仍计入：需要 {技能} {等级}”（英文 Level too low; included: requires {skill} {level}）；提示不阻止计算。对应品质不存在时不计入属性，并显示原因。双手大剑与副手冲突时，副手仍不计入计算，即使大剑等级不足。跨流派护甲与副手按下文排除。验收覆盖低等级武器及防具的属性与模拟输入、达到穿戴等级后提示消失，以及低等级双手大剑的副手排除。
- 利维坦护符的原始穿戴门槛为总等级 750；战斗配置只有五项技能，不核验完整总等级，也不生成此门槛的配装提示或计入精通页提示数量。手动选择、导入与存档恢复均保留护符，属性和模拟照常计入。没有其他配装问题时隐藏提示框。验收覆盖五品质、强化、低／高技能等级、导入／存档恢复及双语桌面／窄屏，其他配装提示仍按上述规则显示。
- 装备下方小字显示当前品质、强化后的所有非 0 属性：命中、力量、防御、武器基础攻击间隔（原始刻数换算为秒）、幸运加成（百分比）；隐藏 0 值或不存在的属性，无装备或无非 0 属性时显示“—”。坐骑显示非 0 移动速度加成。中英文同步，配置修改后实时更新；不改变战斗计算规则。验收覆盖武器、防具、护符、坐骑、空装备及品质／强化更新。“显示全部装备”可查看及保留其他流派的配置。帽、胸甲、腿甲及副手需与武器流派匹配，空手按近战处理。旧存档或手动配置中的不匹配装备保留在配置并提示，在属性、世界首领静态估算及逐刻模拟中均排除。

#### 3.3.3 食物与药水

- 食物菜单依次为“食物”“食物稀有度”“每趟携带”“自动进食阈值”“食物伤害增益生效 +25%”“作物减伤增益生效 −20%”。不展示单次治疗量、增益持续时间、增益分组标题或应用增益按钮。
- 两个增益开关独立控制对应效果，选择食物不自动改变开关。稀有作物可同时提供伤害与减伤增益，两者不互斥。
- 自动进食阈值仅提供 25%、50%、75%，默认 50%；每趟携带仅提供 5、10、20、留一格、满包，默认满包。旧阈值不在选项内时回到 50%，旧携带量不在选项内时回到满包。补给条件见 3.3.5。
- 自动食物策略和自动进食稀有度上限不提供界面控件，但保留旧存档与角色导入的字段及模拟语义。指定食物按完整物品编号匹配，不受自动进食品质上限限制；优先好食物、优先差食物遵循品质上限，仅泉水不自动进食。角色导入选食规则见 3.2。
- 药水界面从原始定义筛选影响战斗的 7 种：猎手药剂、战士补剂、矿脉灵药、深渊补剂、疾行药剂、滋养药剂、急速药剂。不提供采集者药剂或倒计时输入。
- 药水按原始草药学配方的制造等级升序显示，同级保持原定义顺序；中英文均仅显示药水名称，不显示等级标识。等级仅用于排序，不限制启用；品质选择和已保存配置仍按药水 kind 关联。
- 每种药水支持未启用和五种品质。战士、滋养、急速药水分别参与相关战斗属性、食物治疗和攻击间隔计算。
- 药水下方按所选品质显示原始规则的实际加成。战士补剂分别显示固定命中和最大伤害百分比，未启用时加成显示为零。
- 猎手药剂、矿脉灵药、深渊补剂参与小时掉落、经验和金币计算；疾行药剂影响移动与补给往返。

#### 3.3.4 家园与精通

配置项由原始定义筛选，覆盖静态战斗和独立小时模拟的参数；不能仅按是否改变面板伤害判断。储藏室只影响有限仓库容量，在当前配置模拟中无效。原始数据完整保留。

| 类别 | 当前完整清单 |
| --- | --- |
| 家园（7 项） | 训练场、练武木桩、盔甲架、箭靶、祭坛、幸运神龛、储藏室 |
| 精通（6 项） | 经验获取、移动速度、生命上限、最大伤害、命中、寻宝 |

- 家园输入表示已放置设施的等级，0 表示无有效加成；仅按家园与精通菜单的等级生效；移除放置与升级设置，默认不在升级中，忽略旧手动存档中的放置开关和升级计时；坐标布局和建造成本不影响当前战斗加成，不需要填写。
- 原始家园建筑等级上限为 50，输入限制为 0–50 整数。
- 练武木桩、箭靶、祭坛对应近战、远程、魔法，每级增加 0.5% 伤害，50 级提供 25% 加成；原始公式仍保留 50% 伤害加成封顶，但当前建筑等级上限不能达到该值。
- 精通使用实际有效加成输入，百分比类以百分数显示，命中精通每级 1%、步进 1 个百分点，其他战斗百分比精通每级 0.5%、步进 0.5 个百分点；内部转换为原始精通等级后调用游戏函数。旧等级存储需无损迁移显示；强化成功率原始每级为 0.25%，已有数值不得因改步进丢失。离线时长按原游戏界面基准 24 小时换算额外小时数（每级 0.12 小时），不能误标为百分比。
- 命中、最大伤害、生命精通参与面板计算；经验、寻宝及相关家园效果参与小时利润；其余效果根据原始模拟实际支持范围标注。

#### 3.3.5 完整手动模拟条件

- 天赋提供口袋、丰盛餐食、休息，等级上限取原始定义，旧配置缺省为零；丰盛餐食为 0–10，影响治疗量。统一展示名称、等级输入及每级效果，名称不附加“等级”；不提供稳手、快手。
- “其它”提供公会经验、世界增益经验、世界增益稀有发现及矿脉祝福。世界经验沿用 `manual.weeklyXp`，世界稀有度使用 `manual.worldRarity`；两项默认 0%，支持小数，输入步进 0.1%，范围 0–10000000%。旧普通配置缺少稀有度时默认 0。两项通过原始 context 窗口全程生效，分别与原始经验、稀有度增益按加法规则叠加，不模拟现实到期或目标完成进度。
- 导入汇总捕获时 `fromTick <= worldTick <= toTick` 的全部窗口，不按名称筛选或去重；省略倍率视为 1，分别累加 `(mult - 1) * 100`。窗口起止为非负安全整数，结束不得早于开始；倍率接受 1–100001 的有限数，汇总超过输入范围时明确回退警告，不截断冒充正确结果。有效空列表清零；异常世界数据两项清零并警告。旧角色快照缺少完整捕获能力标记 `worldBuffsVersion: 1` 时清零并提示更新脚本、刷新游戏重新捕获，不能推断缺失稀有度为无增益；其它角色字段仍正常导入。
- 世界增益经验与世界增益稀有发现下方均显示说明“导入捕获时生效的世界增益，整个模拟周期保持生效。”（Imports world buffs active at capture; they remain active throughout the simulation.）。热门仍独立处理，不重复计入世界倍率。
- 手动启用的药水、祝福、初始食物伤害/减伤均永久生效，移除剩余时间设置并忽略旧计时。未预先启用、仅在模拟中进食获得的食物增益沿用原始规则。规范化配置不再生成已移除的经验进度、实际库存、增益计时、家园放置／建设覆盖和自定义事件字段；读取旧存档时丢弃这些字段，不恢复旧功能。验收保留旧字段输入与无覆盖配置的计算对照，并检查规范化结果不含废弃字段。
- 所选食物固定充足，仓库容量无限，初始背包和溢出区为空。无实际库存、容量和购买格数输入，忽略相应旧存档；进食策略见 3.3.3。
- “其它”提供模拟初始仓库位置：自动（默认）、仓库 1、仓库 2。自动逐敌人选择最近仓库，指定模式固定使用该仓库，结果列表显示实际模拟仓库；有效旧指定值保留，缺省或无效值回到自动。铁人模式可配置；家园有效条件见 3.3.4。
- 比较的是独立目标战斗，初始满血、从仓库出发、原预测刻由游戏规定；当前血量和所在坐标被原预测重置，不作为误导性的可编辑项。无任务队列、后备任务、并行强化或农田作业的独立战斗是手动场景边界，不混入其他工作利润。
- 不提供内部复现参数菜单。角色编号固定为 1、角色时间刻为原始预测刻，忽略旧手动存档中的对应覆盖值。战斗页面每轮启动模拟时用 `crypto.getRandomValues()` 生成一个 32 位无符号公开 seed，同轮全部怪物共用，通过原始 context 接口传入；不修改提取代码或原始随机算法。运行种子不写入角色配置，额外耗时明细不显示本轮种子；程序调用可显式传入种子复现，未传入时保留 seed 0 的确定性基线。不能保证模拟与账号单次随机结果逐数相同，也不保证每轮每项结果都变化。

战斗回仓进食规则：存包后、取下一趟食物前，进食阈值大于零时先按原始仓库食物选择直接进食；下一份治疗会超过最大生命、没有可用食物或达到原始循环上限时停止，不保证恰好满血。此阶段不以战斗进食阈值限制目标血量；之后取出本趟食物，再按原有阈值连续进食，最多 64 次。仅泉水禁食、无可食用食物与不足一份治疗空间时遵循原始边界。两阶段的 `ate` 事件均计入食物数量与成本，不占用同一份携带食物。验收包含最大生命 85／熟金枪鱼治疗 12／起始血量 12 时吃六份至 84、起始 60 高于 50% 阈值仍补至 84、禁食／无食物／治疗溢出边界，以及新版原始预测对照。

### 3.5 静态计算规则

以下规则来自已保存的游戏代码快照，用于解释与验收，不作为另写一套公式的理由。实际运算优先调用原始函数。

1. 普通怪物单次最大伤害直接使用角色最大伤害，不按敌方护甲再扣减；不同普通怪物的最大伤害相同属于当前代码行为。
2. 基础最大伤害为 `1 + floor((攻击技能等级 + 装备力量) / 系数)`；当前普通武器及短弓系数为 8，法杖 4.5，大剑 6，长弓 5。
3. 装备先乘品质倍率 1/1.3/1.6/2.2/3 并四舍五入，再乘 `1 + 0.06 × min(20, 强化值) + 0.10 × max(0, 强化值 - 20)` 并再次四舍五入，不合并取整。
4. 战士药水与食物伤害加成相加，随后乘家园流派伤害倍率、最大伤害精通倍率及地牢套装倍率；总增益倍率大于 1 时按原代码向上取整。
5. 命中值采用对应攻击技能和有效装备属性，叠加战士补剂，再计入命中精通并取整。
6. 命中率为 `命中值 / (命中值 + 10 + 目标防御 × 原始武器护甲倍率)`；魔法倍率 0.5、大剑 0.75、长弓 0.9、其他 1，固定 10 不参与穿甲。静态表与逐刻引擎使用同一原始 `armourMultiplier`，涵盖品质／强化和新装备。
7. 当前普通战斗计算无暴击。护甲提高闪避，不直接扣减敌方每次伤害；作物增益提供减伤。
8. 游戏刻为 600ms；静态平均攻击间隔不等于完整战斗事件时间线。
9. 普通战斗命中与伤害随机数使用原始整数混合后的 `randomFloat`，不能沿用更早快照直接将未混合样本除以 2³² 的结果；独立固定输入向量需保持对齐。

## 额外耗时统计与展开

额外耗时显示非目标作业刻数占实际模拟总刻数的百分比，主表及展开各项占比均固定显示一位小数；零总耗时显示“—”，排序使用未舍入比例，不按天折算。目标作业包括战斗攻击间隔、采集／制造完成判定等待、失败与烧焦尝试；其余全部计入额外耗时，包括行走、仓库操作、补给恢复、被抓停顿和阶段切换。每刻互斥分类，作业与额外之和等于实际总耗时，沿用原始停止边界。

展开先显示实际模拟、目标作业耗时和额外耗时，再在额外耗时下方以紧凑缩进与左侧细线分组显示非零的行走、仓库操作、补给与恢复、被抓停顿、流程切换、其他等待；汇总行不加粗，不添加底部标注。细分标签使用次要文字色，数值保持清晰；两列间距压缩，沿用明细最大宽度 230px，标签可换行，底部仓库与次数信息和耗时分组留出间距。被抓停顿仅统计工作状态下尚未解除的被抓停顿；流程切换统计存在路线时的非作业阶段切换，两项互斥。各项比例均以实际总耗时为分母。时长只显示最大单位（小时／分钟／秒），其余折算小数，最多两位小数并去掉末尾零；0 显示“0秒”，非零且不足 0.01 秒显示“<0.01秒”。单位按未舍入时长选择，比例仍按原始刻数计算；英文使用 h／min／s。底部仅保留初始仓库、回仓／补给次数及适用的被抓次数和停止原因，不显示地点编号坐标或随机种子，不添加独立速率模拟说明。概率与理论单次耗时保留于次数列。

验收覆盖分类互斥及总和、取料回仓、补给恢复、偷窃停顿、装备升级、提前停止、零耗时、排序、双语及展开保留；同种子产量、经验与原有计时不因统计改变。
