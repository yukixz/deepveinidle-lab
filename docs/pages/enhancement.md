# 强化页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

### 4.1 页面布局与角色配置

- 左侧“角色配置”包含导入、技能、家园、精通及保存提示；右侧为“强化配置”（Enhancement settings）面板与结果（4.4），布局与折叠遵循[共用页面规则](../shared.md)。
- 强化技能等级、已放置的有效符文书台等级、强化精通实际加成独立编辑。技能说明仅显示“强化技能每比 1 级高一级，成功率倍率增加 0.2%。”，英文为“Each enhancing level above level 1 adds 0.2% to the success chance multiplier.”。
- 家园标签为“符文书台等级”（Rune lectern level），精通标签为“强化精通实际加成 (%)”（Effective enhance mastery bonus (%)）；精通以实际百分比输入，步进 0.25%，内部保存原始等级。精通原始等级上限 200，导入及旧存档越界明确拒绝，实际加成最多 +50%；手动实际加成输入范围 0–50%。
- 配置使用独立 localStorage 键自动保存，存储失败明确提示；左侧“清空配置”仅恢复强化技能等级、符文书台、精通及导入公会信息，保留右侧装备、保护和价格覆盖；强化编辑不重算战斗。

### 4.2 装备、保护与价格设置

- 装备与工具使用共用目录和原始强化资格。新目标按物品上限校验，现有 +0–+100 的历史强化仍可按完整物品 ID 读取。目标等于当前时强化成本为零。超限的旧方案保留并明确提示调整目标。
- 装备仅提供可搜索选择框，无类型筛选。中英文名称支持大小写无关子串匹配；仅点击或键盘确认候选才改变配置。支持方向键、Enter、Escape、Tab、无匹配提示及限高滚动；关闭时清除搜索文字并恢复已选名称，未确认文本不写入配置。刷新、语言和板块切换保留已选装备。
- 强化配置采用紧凑排版，不显示标题下的介绍句；收紧面板内边距及行间距，保留输入框尺寸和全部参数。装备/工具与品质同行等宽，窄屏也保持同行。宽屏（至少 1200px）将当前强化值、目标强化值、“使用保护卷轴”与“保护卷轴起始等级”（Protection scroll starting level）按此顺序等宽同行；其余屏幕按同一顺序两列排列。保护卷轴采用下拉选项“使用／不使用”（Use / Do not use），默认“使用”；切换立即更新计算并保存，沿用布尔存储字段，旧方案的选择保留。
- 提供无保护或从指定当前 +值开始保护，阈值 +1–+100。按选定策略假设材料与卷轴充足。默认关闭巨像核心，开启后在原始基础成功率低于 100% 的尝试中消耗一个核心，额外增加 3 个百分点，然后应用保底。核心不替代碎片。
- 右侧“强化配置”面板右上角提供“清空配置”（Reset settings），仅重置该面板全部参数，保留左侧技能、家园、精通、公会信息及导入状态，不修改全局价格。首次与右侧清空配置默认马（Horse）、传说、当前 +0、目标 +10，保护卷轴选择“使用”、从 +2 开始保护；已有保存方案保留原值。
- “价格与收费设置”固定展示“虚空碎片”“保护卷轴”“强化精华”“巨像核心”“底装购置费”五个金币价格输入。宽屏（至少 1200px）五项等宽同行，其余屏幕等宽两列。“市场税率 (%)”（Market tax rate (%)）与“期望利润率 (%)”（Expected profit margin (%)）独立等宽同行。材料选择无价值时，材料输入显示零并禁用，切回其他来源后恢复原覆盖。
- 输入框显示当前有效价格。未覆盖时通过[价格模块](../modules/item-prices.md)读取锁定价或所选材料报价，底装默认取 7 天均价。编辑只覆盖当前强化方案，清空表示本方案未定价，填 0 表示免费或已有底装。右侧清空配置取消方案价格覆盖，左侧清空配置保留覆盖。旧方案保留已有价格选择，强化精华和巨像核心补用全局价，核心默认关闭。底装费用关联完整物品编号，切换装备、品质或当前强化值时恢复对应全局价，材料覆盖保留。缺少所需价格时提示未完整定价，底装费用单独计入完整定价后的总投入。

市场税率默认 3%，期望利润率默认 10%，均允许有限数值 0 ≤ 值 < 100（百分比输入，可填小数），两者之和必须小于 100%；空值或越界明确报错。税率 t 按总收费计税；利润率 m 定义为税后利润／总收费，后四项收费分别以强化成本均值或分位数 C 加底装购置费 B 为总成本，计算 (C＋B) ÷ (1−t/100−m/100)，税后利润为收费×(1−t/100)−(C＋B)。底装计入利润，不额外叠加旧 3% 预算预留。税率与利润率均为 0 时收费为总成本；材料价格与消耗不受两者影响。旧存档仅在缺少 taxRate／profitRate 字段时分别补 3／10，保留已有利润率，显式非法值不得替换；自动保存及刷新恢复，左侧清空保留、右侧清空恢复 3%／10%，导入角色保留手工税率与利润率。

方案配置须包含明确的价格模式与底装完整 ID 绑定，不从旧价格数值推断这两项；无全局价且无有效覆盖时仍为未定价。

1198 保存的配置不包含 lectern，读取时仅为缺失字段补 0；不覆盖显式存在的非法值，保留其他配置。1199 的角色导入重新校验 house／houseFurniture 和已放置书台等级，缺失或非法时明确失败并保留当前配置。恢复书台后可手动填写，或重新导入完整角色数据。

### 4.3 角色配置导入

角色导入区域提供默认关闭的“自动更新角色配置”，使用[共用角色自动更新](../shared.md#导入游戏角色与自动更新)；更新范围沿用本页手动角色导入，不新增库存自动更新。

- 复用 [共用导入协议](../technical.md#61-角色导入组件与-userscript-协议)的共用导入容器、连接检测及双语状态，仅提供“导入配置”，无快照操作。不要求先打开游戏战斗预测列表。
- 使用普通角色桥接 2.4 与 requestCharacter（脚本版本见 [当前状态](../status.md#已发布基线)） 读取最近 snapshot.player，校验技能经验、书台等级/放置及从[强化技能对应精通页](../shared.md#导入精通页)读取的精通，并转换为固定等级配置。
- 仅导入强化技能、已放置书台、精通及公会信息，保留右侧手工强化方案；不读取装备或库存，不提供角色物品快捷选择，也不保存完整角色或库存。所需角色字段缺失、非法数据或脚本失败时明确报错并保留原配置；不覆盖战斗配置。

### 4.4 结果展示与范围边界

- 依次显示“平均强化投入”“收费测算”和“逐级成功率与单次费用”，中英文顺序相同。
- 表格展示各级成功率、单次金币、碎片、强化精华、巨像核心及失败去向，列出起始等级以下可能重做的步骤。高阶成功率展示从零保底到保底上限的范围，并说明估算从零保底开始。
- “平均强化投入”（Average enhancement inputs）按金币、碎片、保护卷轴、精华、巨像核心、次数、耗时展示七张卡片，包含失败回退与重做。宽屏（至少 1200px）采用八列同行，中等屏幕四列，窄屏（至多 740px）两列。金币卡占两列，其余各占一列。该组使用紧凑内边距和 22px 数值。
- “收费测算”（Fee estimates）展示两组各四张金币金额卡片。第一组“平均投入成本”“80%保本期望”“90%保本期望”“95%保本期望”合计强化金币、碎片、卷轴、精华及核心，分别为均值与完整路径成本分位数的保守上界。分位数卡片统一显示“至少 80%／90%／95% 的概率不超过此金额”。
- 第二组“平均收费”“80%保本收费”“90%保本收费”“95%保本收费”按第一组对应成本 C 和底装购置费 B 计算 (C＋B)÷(1−t/100−m/100)。两组各在卡片上方说明计算依据。四张收费卡片下各显示对应税后利润，公式为 (C＋B)÷(1−t/100−m/100)×(1−t/100)−(C＋B)。底装或所需材料缺价时，利润显示“未完整定价”。
- 所需材料未定价时，两组均显示“未完整定价”；底装未定价时，第一组照常计算，第二组显示“未完整定价”。零消耗材料无需定价，已有底装需填 0。达到目标时第一组四项为 0，第二组四项等于底装费÷(1−t/100−m/100)，税后利润为收费×(1−t/100)减底装费；底装费为 0 时收费和利润均为 0。市场税仅计入收费换算，不增加底层强化成本。
- 分位数由后台 Worker 计算确定性的离散成本分布。配置或价格改变后取消旧任务，防抖 150ms 后开始计算。计算中即时保留期望成本。资源超限、精度校验失败或 Worker 失败时，三档显示原因，保留均值。
- 收费测算内所有金币金额（平均成本、三个保本成本、平均收费、三个保本收费及四项利润）均在显示时向上取整到个位，使用完整整数与千分位，不使用科学计数法或保留小数；内部仍用未取整成本和利润计算，不逐步累积取整。利润直接列在收费卡片下，不设独立估价明细面板。上方平均强化投入统计精度不变。
- 强化期间技能等级固定，不模拟经验增长导致的升级；每次耗时 2.4 秒，不含界面等待。平均强化投入汇总中的大数使用科学计数法，限制有效位数；不可靠结果明确失败。

### 4.5 计算规则

当前 1.0.1228 使用原始资格、物品上限、概率、费用、失败去向、耗时与经验规则。六件陨铁装备的金币档位提高至 12,000。+1–+3 受保护失败保级，+4–+19 受保护失败退一级，从 +20 起受保护失败最低回到 +20。未保护失败归零。仅保护失败消耗卷轴。高强化按档次、品质及尝试等级记录保底，模型按从零保底开始的方案评估，成功清空该级保底。高强化增加精华消耗和巨像核心策略，纳入期望与分位数的成败路径。验收覆盖保护保级、陨铁成本、巨像核心、精华缺价、保底状态转移和物品上限。

以每次首次升到下一强化等级为单位计算期望。向上跨级后，对应等级的保底清零。每次失败先支付失败费用，从失败后等级重做到本级，再按累计失败次数重试。重做的期望等于经过各级的期望之和。保底封顶后的连续重试用几何分布求和，封顶前从最后一档向前累加失败期望。将单次投入乘以预期尝试次数，再将失败专属费用和重做期望乘以预期失败次数。从起始到目标逐级相加。计算包含金币、碎片、卷轴、强化精华、巨像核心和次数，超出有限精度时报错。逐级内部经验在刻 0 调用原始经验入口，估算使用固定技能等级。

#### 成本分布递推

固定成功率阶段沿用《等级升级成本分布递推——编码实现参考》（2026-10-26）。对每级定义 d_k 为单次强化金币及碎片、精华和巨像核心估值之和，r_k 为受保护失败消耗的卷轴费用，f(k) 为原始失败去向：

`F_k(x)=p_k F_(k+1)(x-d_k)+(1-p_k)F_f(k)(x-d_k-r_k)`。

目标态非负预算概率为 1，负预算为 0。预算升序、等级降序，零费用自环代数消除。全部必成时直接求确定费用。分位数基于完成整个订单的总费用。货币输出超出安全精度时明确失败。

固定成功率递推精确合并成功率等于 1 的必成费用。成功和失败去向各自加上通往下一随机等级的必成费用，起点必成费用单独加回。对完整分支费用求最大公约数，以压缩预算网格。

高阶订单只有一步，且失败保级时，按逐次失败概率的乘积直接求每档所需尝试次数及费用。其余含高阶保底的订单按首次升到下一级的费用建立概率生成函数。令 R_k 为从失败去向重做到本级的费用生成函数，p_j 为本级累计 j 次失败后的成功率，则当前函数为 `G_j=p_j z^d+(1−p_j) z^(d+r) R_k G_(j+1)`。保底封顶时，连续重试化为几何级数。各级首次通过的函数相乘，再在半径小于 1 的圆上取样，用快速傅里叶逆变换还原预算分布。选定半径使超出采样周期折回的累计概率最多为 `exp(−12)`。分位数下界使用目标概率减 `10⁻⁶` 的浮点缓冲，上界使用目标概率加折回上限和同样的浮点缓冲。累计概率超出该数值容差，或原始费用网格仍无法收紧到所需精度时，明确返回精度失败。

#### 均值关联费用网格与误差控制

平均强化成本 C 使用原始报价。C=0 或已达到目标时返回零强化成本，收费按底装价格照常换算。非零时以 `10^(floor(log10(C))−4)` 选初始网格 h。固定成功率递推先按十倍细化 h，确保 h 不超过最低单次基础费用。含保底的生成函数可直接处理费用取整后的零成本分支。

价格十进制精确整数化。固定成功率模型对基础费用及失败卷轴费分别向下、向上取整。含保底时对成功和失败的完整费用分别向下、向上取整。相同强化路径的费用满足下界≤原费用≤上界，相应分位数满足 Q−≤Q≤Q＋。三档同时满足 `(Q＋−Q−)/Q− ≤ 0.001`（0.1%）时，显示 Q＋。未达标时固定成功率细化十倍，含保底时根据最宽区间的超额比例细化。下界为零时只接受上下界都为零。当前网格可精确表示所有费用时只求解一次，仍校验含保底模型的数值缓冲。

计算结果保留保守上界、下界及可证明超额界，不能将上界模型中的实际 CDF 冒充原费用模型覆盖概率。页面统一显示“至少 80%／90%／95% 的概率不超过此金额”（英文“At least 80%/90%/95% probability of staying within this amount.”），不展示保守估算、误差比例或实际 CDF 等术语；0.1% 容差仍由后台验证。收费使用对应上界加真实底装费，再按税率与利润率换算；均值与税后利润沿用上述收费换算规则。误差承诺针对内部未显示取整的强化成本，不包括最终金币向上取整到个位；页面不展示精确 CDF 覆盖概率。

固定成功率递推使用滚动数组，含保底时存储傅里叶变换的实部和虚部。每次求解最多存储 5,000,000 个 Float64 单元（约 40 MB），上下界及所有细化轮次共享 500,000,000 个计算单元。固定成功率按等级和预算单元计量，含保底按采样点的逐级尝试分支及变换规模计量。结果需要三档同时满足精度要求。高目标或低成功率可能触及内存或运算上限，页面显示具体原因并保留均值。

### 4.6 验收与验证边界

- 核验旧存档补默认值、书台输入、角色导入、2.4 秒耗时，以及原始碎片、精华和经验规则。
- 核验装备与工具的目录、品质、逐件强化上限、陨铁金币档位、保护保级和高阶保底。覆盖零成本、必成、不同失败去向、旧目标报错和 +100 已有装备。
- 核验左右清空范围隔离、导入后不显示角色物品快捷选择、价格覆盖保留／恢复全局价、自动保存与双语窄屏按钮布局。
- 核验首次和右侧清空的默认马、传说、+0 至 +10、启用保护与关闭核心，保护和核心切换及刷新恢复，五项价格、两种语言、宽窄屏布局、全局价及方案覆盖、底装换装绑定。
- 核验导入字段、失败原子性与战斗隔离，材料空价和底装估价、八张成本／收费卡片与含利润费用（强化成本加底装后除以 1−t/100−m/100）与缺价提示、四张收费利润值、底装缺价时利润不可用、达到目标时底装仍计利润、无金币估价面板、汇总字段顺序，搜索确认/取消、键盘操作、保存恢复、双语、共用页面导航及窄屏。
- 用独立路径传播验证固定概率、多个保底计数并存、卷轴、重走和非零起点。验证实际高阶方案、上下界包含精确值、精度校验、共享内存及运算上限、Worker 旧响应隔离和双语失败提示。验证税率、利润率、缺价、储存和重置。
