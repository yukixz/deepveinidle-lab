# 共用页面框架

[设计索引](../DESIGN.md) · [当前状态](status.md)

战斗、采集、制造页面统一使用“利润”称呼扣除既定成本后的金额，适用于表头、周期选项、汇总、提示与说明；英文沿用 Profit。计算口径、排序、周期折算及存储字段保持既定规则。验收要求：三个页面的应用文案不再出现“收益”，原有利润计算及交互保持一致。

数值、次数、百分比和掉落期望数量的展示规则见[数字格式化设计规范](number-format.md)。

### 2.1 导航与网址

- 右上角版本标识中英文均只显示当前包版本号，不添加“正式版”、测试版或 BETA 前缀。

- 页头提供同级“战斗 / 采集 / 制造 / 强化 / 精通 / 技能首领 / 预报”导航（英文 Combat / Gather / Crafting / Enhance / Mastery / Skilling Bosses / Forecast），网址依次为 `/combat`、`/gather`、`/craft`、`/enhance`、`/mastery`、`/boss-feed`、`/forecast`，首页 `/` 显示战斗。战斗角色配置、属性与敌人利润归入战斗板块。

  公式页不出现在导航菜单，通过 `/formulas`（支持尾斜线）直接访问，使用独立阅读布局，详见 [公式页面](pages/formulas.md)。

  使用统计页通过 `/usage`（支持尾斜线）直接访问。导航菜单不显示此入口，数据通过管理员密钥解锁。 [使用统计页](modules/usage-statistics.md#使用统计页)
- 未匹配任何页面的 URL 路径临时重定向（302）到 `/combat`，地址栏同步变为战斗页地址，不在原错误路径下直接展示战斗。已知页面、尾斜线及首页 `/` 的行为不变；前端处理历史导航中的未知路径时使用替换当前历史记录的方式归一到 `/combat`，避免后退反复回到错误地址。未知路径的查询参数与片段保留，与 Cloudflare Pages 重定向行为一致。托管规则在通配重定向前为首页、HTML 入口及 `src/`、`vendor/` 静态资源保留 200 映射，避免资源被重定向。本地服务继续拒绝受保护的文件路径。验收覆盖未知单层／多层路径、全部已知路由、静态资源正常访问和前端历史导航兜底。
- 导航使用真实链接，普通点击通过 History API 更新网址并切换内容可见性；支持复制链接、新标签打开与浏览器前进／后退。切换板块保留角色配置、搜索、筛选、排序、折叠状态和已有模拟结果。进行中的采集与制造模拟继续完成；战斗模拟随战斗板块暂停与接续，见[连续模拟与结果统计](pages/combat.md#36-连续模拟与结果统计)。语言切换保留当前板块；直接打开或刷新按网址显示相应板块，不新增板块存储字段；刷新仍按原规则重置未持久化的筛选。
- 导航位于品牌与语言控件之间；窄屏时在页头内独占一行。页头、语言控件及项目页脚为各页面共用。导航支持键盘操作，有明确选中状态，中英文与窄屏均可用。

收藏页已移除。`/collection` 与 `/collection/` 按未知路径规则跳转到 `/combat`，客户端历史导航兜底保留查询参数与锚点；不加载收藏页面、计划或自动更新控制器，不读写旧收藏专用存档。精通页继续使用游戏收藏数据计算点数。验收覆盖两个旧地址的 HTTP 跳转及客户端历史导航、页面无收藏容器／资源请求，以及精通共用功能回归。

调试页网址为 `/debug`（也支持尾斜线），不出现在导航菜单；通过网址进入，沿用语言、页脚和页面状态保留规则。调试内容网格及文件输入在中英文 390px 下不得撑宽页面。

### 2.2 语言、布局与持久化

- 右上角语言切换入口仅显示语言图标，不显示当前语言文字或下拉箭头；打开后仍使用原生下拉选项“简体中文 / English”。保留“Language / 语言”无障碍名称、悬停提示及键盘焦点。验收覆盖双语桌面与 390px 窄屏的图标显示、选项不变、鼠标／键盘切换及刷新后语言保留。
- 支持简体中文和英文；公式页面正文、目录与提示仅中文，站点语言切换不翻译公式。优先使用已保存的手动选择，否则浏览器语言列表包含中文时默认中文，其余默认英文。
- 游戏名称优先复用上游翻译字典；缺失翻译及已核验的新版说明集中补充。新增选项必须同时覆盖两种语言，中文模式不能遗漏药水、家园、精通名称或说明。
- 游戏文本核对范围为 `src/` 手写模块及 `index.html`，以本地已核验原始资源中的四组翻译为依据。相同含义的技能、属性、设施、药水、稀有度及特权名称复用原文与译文；补充字典仅作为上游缺词的回退，不能覆盖已有翻译。金币英文统一 Coins，避免与 Gold（金矿物品）混淆。复合说明保留模拟器限定语，仅统一其中的游戏术语；统计表的所需等级、采集次数及价格锁定等保留实际语义，不机械套用游戏不同上下文的译文。

  验收要求：逐项明细列明替换、现有复用、缺词回退和上下文保留；双语相关渲染及翻译优先级验证通过，不改变计算或保存协议。家园分组中文统一使用游戏已有“家园”（Home board 的译文）；英文 Home 保持不变，不能机械按 Home 的短译“家”缩写。术语核对明细见 [游戏文本核对报告](../reports/game-text-audit-2026-10-14.md)。
- 语言切换遵循 [导航与网址](shared.md#21-导航与网址) 的状态保留规则。所有页面的“导入游戏角色”首次打开或刷新默认展开，其它角色配置子菜单默认折叠，可独立展开或折叠。战斗、采集、制造、强化和精通的「角色配置」面板与战斗、采集、制造、强化和技能首领的「模拟配置」面板也可独立折叠，默认展开。标题支持鼠标和键盘操作，折叠时保留标题并隐藏面板内容及清空按钮。折叠不重跑模拟。面板和子菜单的展开状态在重绘、切页及语言切换间保留，刷新恢复默认。
- 「角色配置」右上角的「清空配置」只恢复该面板的角色参数。战斗、采集和制造保留「模拟配置」中的时长、热门加成及敌人／任务选择；采集已选单个任务时同时保留其所属技能，以维持任务有效。强化保留右侧强化方案和收费设置。精通重置点数模式、总点数、当前及目标等级，保留已保存方案和历史最优。
- 「模拟配置」面板右上角提供「重置设置」，恢复该面板的模拟条件与物品价格选项。战斗默认全部敌人，采集默认当前技能的全部任务，战斗、采集、制造默认 24 小时及按照当前时间，强化和技能首领仅恢复材料价格来源。两个重置入口均保留全局行情与锁定、角色自动更新开关、另一面板的设置以及其它页面的配置。更改模拟条件重新模拟，仅更改价格选项时沿用模拟结果。
- 战斗、采集、制造、首领投喂、强化、精通页在宽度大于 740px 时采用固定视口工作区。页头保持可见，左侧配置与右侧信息分别独立纵向滚动，到边界不带动外层页面。右侧属性、结果、说明与项目页脚整体滚动，表格可独立横向滚动。工作区高度由实际页头高度自动分配。宽度不超过 740px 时恢复上下排列与整页滚动，页脚位于全部内容末尾，页面宽度适配视口。各页配置面板与结果列使用相同的可用宽度，折叠面板时左右边缘保持对齐。
- 上述六页切换、语言切换及配置／结果重绘保留各列滚动位置（内容变短时由浏览器裁剪）；不新增持久化字段，不改变计算或模拟流程。验收覆盖上述页面的双语桌面、页头换行、左右滚动互不影响、页脚可达、键盘操作、重绘及页面切换保留位置、390px 上下布局。
- 使用浏览器 localStorage 自动保存语言及角色配置。旧配置按各字段的默认值和迁移规则规范化，未单列的新增字段补零或未启用；非法数据不得导致页面崩溃。
- 存储不可用时提示保存失败，计算仍应可用。

桌面 1401–1480px 页头导航减小水平内边距，保证英文导航和右侧控件不溢出；窄屏右侧控件区限制在页头可用宽度内并自然换行。

战斗、采集、制造和技能首领在 740px 及以下共用装备布局。部位标签在装备名称上方，名称选择框独占一行，下一行并排显示等宽的品质与强化控件。三个控件均为 32px 高，装备效果列在下方。

#### 任务表格模拟状态

战斗敌人列表、采集任务、制造配方选择的模拟状态统一放在各自标题栏最右侧，包括进行中、进度、等待及失败信息；保留已有状态文案、更新时机与完成后的隐藏规则。采用小字、右对齐，长文及窄屏可自然换行，不截断失败原因，不占用搜索工具栏下方的独立提示行。配置、价格及行级不可用原因保持各自原位置。验收覆盖三页双语桌面／390px、进行中进度更新、失败及完成隐藏，保证页面无横向溢出。

### 导入游戏角色与自动更新

“导入游戏角色”共用模块负责战斗、采集、制造、首领投喂、强化和精通的自动更新设置、读取调度和状态。每页提供独立的“自动更新角色配置”（Automatically update character configuration）开关，默认关闭，保存在 `dvi-character-auto-import-<页面>-v1`。清空页面配置时保留开关。旧制造设置保留 config，后续保存删除 inventory。坏设置明确提示并停止自动读取，用户重新选择后恢复保存。

勾选后立即更新；进入页面、刷新恢复及该页活跃时窗口聚焦触发，不轮询，语言及结果重绘不触发。手动导入和自动更新共享忙碌状态，进行中的重复触发合并。离页、关闭／改变开关、重置或编辑期间的旧响应不得覆盖新状态；未提交输入暂缓自动更新，下一次触发重试。失败保留已有数据和开关，显示错误，后续触发可重试。

自动更新通过现有 `read` 取得完整快照，按页比较快照的 `capturedAt` 与本次页面会话内上次成功导入并保存的记录。技能首领手动导入或读取到新快照时应用所有首领的技能等级与精通。技能首领还比较所选首领，同一快照仅刷新新首领的等级、工具、家园及共用配置，保留已保存的精通。比较值均相同才跳过应用、配置保存和结果重绘。站内切页保留内存记录，刷新或新标签重新开始，显式清空页面配置时清除本页记录。手动导入始终应用读取到的快照。手动或自动导入成功保存后更新记录，失败或失效响应不更新记录。切换技能或首领时作废读取中的响应。

配置更新只使用各页既有角色映射，保留模拟时长，不导入不相关字段或另一页配置。制造不读取真实库存，也不校验库存；完整捕获与战斗选食所需仓库数据继续保留。

验收覆盖六页开关、独立保存和默认值、旧制造开关兼容、设置损坏保护、手动互斥、进入／焦点／返回与无轮询、编辑及迟到响应隔离、失败保留／重试、完整读取后的去重、跨页隔离、站内返回保留、刷新和重置清除、手动强制应用及保存失败后重试，以及双语桌面／390px 布局。

#### 导入精通页

战斗、采集、制造和技能首领在各自的浏览器存档中按技能保存精通。导入一次取得各技能的初始精通，手动调整只应用于当前技能。切换战斗流派、采集技能、制造技能或首领时，立即应用对应技能已保存的等级，首次手动配置的技能默认为 0。旧存档中的单套精通归入保存时选中的技能。战斗首次导入应用武器对应技能，空手按近战，武器无法判定时将游戏当前页用作默认近战配置的初值。强化按固定的强化技能选页，[精通规划页](pages/mastery.md#页面与配置)使用角色快照中当前激活的精通页。

按游戏内技能绑定选页，绑定指向当前页时读取该页，指向已拥有的备用页时读取完整备用页。备用页存在但为空时各项等级按零处理。单页角色、技能未绑定或旧快照没有多页信息时使用当前页。可识别的绑定指向缺失页、无效页号或非对象页时，回退当前页并明确提示；选中页的等级字段沿用[各页面原有校验规则](#上游等级上限)。选页仅影响实验室导入的精通等级。

导入成功状态显示捕获时间，并在精通绑定无效时提示已使用游戏当前设置。验收覆盖两个激活页方向、绑定当前页、空备用页、单页／未绑定／旧快照、失效绑定和等级校验、关闭自动更新后切换技能、手动调整与刷新恢复、读取中换技能时丢弃旧响应，以及双语导入状态。

### 2.3 项目页脚

- 项目页脚在上述五页桌面布局中位于右侧信息末尾，其余页面及窄屏位于页面底部。首行左侧为“项目作者：Alice”（英文“Project author: Alice”），右侧为右对齐的“Deep Vein Idle ↗”，在新标签页打开与页头副标题相同的邀请地址。交流 QQ 群、公开资源日期与游戏版本说明从页脚移除，资源来源见[原始代码复用](technical.md#62-原始代码复用)。
- 验收覆盖中英文桌面／390px 的作者与游戏链接同一行、两侧对齐及链接目的地，并核对页脚文案及版权说明。
- 页脚提供中英文版权与项目关系说明：Deep Vein Idle 的名称、标识、设计、代码、素材、截图、角色、世界设定及其他可识别资源归原游戏作者或相应权利人所有，其他商标归各自权利人所有；本项目为玩家制作的非官方信息与交流工具，由项目作者独立维护，不代表原游戏官方立场或认可，不声称已获得官方授权。窄屏自然换行，不产生页面横向溢出。

### 2.4 页面估值与全局行情

战斗、采集、制造、强化和技能首领的左栏由「角色配置」及其下方独立的「模拟配置」面板组成，共用左栏滚动，窄屏按此顺序排在结果上方。「模拟配置」内的「物品价格」小节提供当前页估值来源及「全局行情与锁定 / Global quotes & locks」入口，各入口打开同一个双语原生弹窗。支持 Escape、关闭按钮、点击弹窗外关闭及焦点返回触发按钮。

弹窗顶部为「更新价格」「自动更新价格」和行情状态，保留物品表、分类／名称／稀有度／强化／状态筛选、手填、锁定与清空未锁定价格。无有效筛选时提示先设置筛选条件。表格展示手填或保留的旧价格、商人价、最低卖价、最高买价、两种均价和两侧全市场数量。手填自动锁定，空值未定价，0 有效，按完整物品 ID 管理。已解锁记录可保留并再次锁定，当前页面估值只使用有效的锁定记录。

<a id="导入策略与存储迁移"></a>

手动更新及自动更新只刷新官方行情快照。打开或聚焦网站时按现有五分钟间隔尝试自动更新，沿用超时、请求合并、防倒退、跨标签去重与错误保留规则。打开弹窗和切换估值来源直接使用缓存。存档保留报价、价格记录、锁定和自动更新开关，移除全局分类选项及即时重定价。详见[物品价格模块](modules/item-prices.md)。

#### 行情同步与物品表

行情来自游戏的官方公开市场接口。手动请求与自动请求合并，10 秒超时，HTTP、网络、空快照、格式错误及整份快照过旧保留旧行情并明确提示。弹窗顶部单独一行显示读取中、错误、操作结果或本地缓存摘要。自动更新无后台轮询，失败也计入五分钟间隔，用户可立即手动重试。自动通知可点击或按键关闭，30 秒后自动消失。

分类沿用原市场一级分类，宝石归资源、坐骑归工具。强化默认 0，清空时不限强化等级。筛选变化清空勾选，弹窗关闭重开保留本次会话的筛选；刷新恢复默认。锁定空值可同时符合「已锁定」和「未定价」。批量操作只作用于勾选项，清空未锁定价格需确认并作用于全部未锁定记录。更新完成、保存失败和行情错误有明确状态。

### 2.5 共用验收

核验品牌名称、各网址直接打开/刷新/前进后退、键盘导航、状态保留和进行中模拟；核验 [语言、布局与持久化](shared.md#22-语言布局与持久化)、[项目页脚](shared.md#23-项目页脚) 的语言回退、翻译、桌面/窄屏、保存失败及页脚。所有页面均须无阻断性脚本错误，旧配置兼容，非战斗字段不虚构战斗效果。源码一致性验收见 [原始代码复用](technical.md#62-原始代码复用)、[上游更新流程](technical.md#64-上游更新流程)。

## 上游等级上限

游戏 1.0.1208 起，全部精通等级为 0–200，全部家园建筑（含符文书台）等级为 0–50；原始成本与加成公式不变。各页面输入上限、配置规范化、角色导入和精通搜索共用已核验的原始上限。战斗／采集／制造沿用规范化规则，将旧本地配置越界值限制到上限；角色导入沿用逐字段警告：战斗的越界家园／精通字段回到默认零，采集／制造保留对应当前值。强化与精通页沿用严格校验，越界旧存档或导入明确报错，不静默调整投入或预算；旧存档读取失败时展示默认配置并保留原存储，直到用户主动修改保存。角色导入的精通来源见[导入精通页](#导入精通页)。

验收覆盖 199／200／201 精通、49／50／51 家园，输入 max、旧配置恢复、逐字段警告及严格导入原子拒绝、精通 MAX／搜索候选不越界，以及现有战斗、采集、制造和强化原始计算对照。
