# 物品价格模块

[设计索引](../../DESIGN.md) · [共用价格界面](../shared.md#24-页面估值与全局行情)

## 数据与职责

行情、角色配置和所有计算页统一使用 1.0.1228 的物品定义和完整 ID 编码。已上市或可交易的物品可查询、手填与锁定价格，商人不收购时商人价为空。粗制宝石归资源的材料。兼容历史强化价格键，市场报价仍按品质与强化区分，遗物进度编码单独解析。验收覆盖地牢钥匙、遗物、稀有度补给、补剂、历史强化与锁定价格。

全局价格模块管理官方行情、锁定价、持久化和请求调度。页面通过 `src/price-service.js` 读取只读快照，通过 `src/page-prices.js` 保存本页设置并按用途取价。

估值层接受页面提供的单价及缺价状态，供结果金额、只读明细和排序共用。独立计算接口保留旧的只读映射入参兼容。

按完整物品 ID 区分品质和强化，提供 `price`（用户物品价格）、`vendorPrice`（原始商人售价，不可出售为 null）、`sellPrice`（最低卖价）、`sellQuantity`（在售数量，全市场在售物品总量）、`buyPrice`（最高买价）、`buyQuantity`（求购数量，全市场求购物品总量）、`avg7d`（7天平均成交价格）、`avg30d`（30天平均成交价格）。六项行情字段依次来自 `lowestSell/sellQty/highestBuy/buyQty/avg7d/avg30d`；挂单总量不是最优价位数量，不用于推算成交能力。商人价不受市场刷新或用户锁定影响。

用户价格空值为未设置，0 为有效价格。官方报价及均价须为正的有限数值，null 为明确无单／无成交记录；数量为非负安全整数，0 为有效空挂单总量。缺失、异常、未读取和明确无单通过字段状态区分，不补 0；数量异常不抹去同份快照的有效价格。数量及其异常状态与价格按同份官方快照存储和替换，不跨快照拼接。

## 价格快照与更新

价格快照按完整物品 ID 提供锁定价格、商人售价和官方行情，旧快照保持原值。价格与行情分别通知页面。手动和自动更新只保存官方快照，存档保留旧价格、锁定、行情和自动更新开关。存档版本为 8，读取旧版存档时迁移保留上述数据，旧版分类定价选项不再参与估值。

## 页面估值

「模拟配置」下的价格设置按页面独立保存，角色导入及角色清空保留该设置。「模拟配置」的「重置设置」恢复本页价格默认值。来源支持成交价（7天）、卖单（最低卖价）、买单（最高买价）、商人价和无价值。默认成交价（7天），战斗的怪物专属贵重掉落默认商人价，复用怪物 bonus 与原市场贵重品的交集判定。强化的材料来源同时用于虚空碎片、保护卷轴、强化精华和巨像核心，底装默认取成交价（7天）。

显式选择无价值时按有效零价计；其余来源依次采用适用的强化方案覆盖、有效全局锁定价、所选来源。方案显式清空仍表示未定价。宠物只统计数量，原生金币不估值。

战斗、采集、制造各有一个「缺价时」设置。默认「提示」按 0 并提示缺价；「商人价」按可出售商人价或 0，不提示；「无价值」按 0，不提示。强化缺少所需价格时显示未完整定价。精通的战斗、采集收入目标继承来源页产出价格来源，在启动时冻结，严格检查缺价；有效零价可以使用。

技能首领投喂的直购和自制原料按本页「材料」来源估算采购额，默认 7 天平均成交价；未定价的采购额留空。供应量读取同一快照的官方卖单数量，报价变化只刷新估价。详见[首领投喂](../pages/boss-feed.md#行情)。

验收覆盖双语桌面和窄屏、配置持久化、锁定与零价、不同用途的同一物品、三种缺价处理、旧存档、行情刷新与失败、战斗采集制造仅重估以及强化分位数更新。

## 上游商人售价兼容

商人价模式和缺价商人兜底统一复用原始售价函数。深渊之眼（基础编号 207）的商人售价为 288,000 金币，保留原始特殊倍率。不可出售的物品没有商人价。火药无市场分类且不可出售，已有有效锁定价仍可估值。
