# 数字格式化设计规范

[设计索引](../DESIGN.md) · [共用页面框架](shared.md)

先完成计算和周期换算，再格式化显示。计算、排序和保存使用未舍入值，输入沿用各字段的原始精度。同类数值在各页面、汇总和明细中使用相同的小数位规则，包括是否保留尾零。零是有效数值，缺失值显示对应状态。

## 通用格式

| 场景 | 展示规则 | 示例 |
| --- | --- | --- |
| 普通数值 | 使用千分位，小数位按字段约定。 | `12,500`、`1,234.5` |
| 紧凑数值 | 绝对值达到 1,000 时依量级用 K、M、B、T，固定两位小数，中英文一致，保留负号。舍入触及下一单位时进位。低于 1,000 按字段约定显示。 | `1.00K`、`-12.35K`、`999,999` → `1.00M` |
| 次数 | 按展示周期折算后，四舍五入到整数并加千分位。 | `1,234.1` → `1,234` |
| 百分比 | 比例乘以 100 后四舍五入并加 `%`，默认最多两位小数。固定精度的字段保留尾零。 | `12.5%`、`12.35%`、命中率 `75.00%` |
| 掉落期望数量 | 零显示 `0`。大于 0 且不足 0.1 时显示 `1/N`，N 为数量倒数四舍五入后的整数，使用千分位。0.1 到不足 10 固定两位小数。10 起四舍五入到整数并加千分位。 | `0.002` → `1/500`、`0.1` → `0.10`、`12.6` → `13` |

## 适用字段

- **紧凑数值**用于战斗的经验（含分技能经验）、金币、掉落估值、收入、食物与药剂成本和利润，采集的经验、金币、主要产物与额外掉落估值、收入、药剂成本和利润，以及制造的经验／天、利润／天、单次材料成本和单次产物价值。绝对值不足 1,000 时，战斗和采集的上述数值四舍五入到整数，制造保留最多两位小数。
- **只读物品单价**用于战斗、采集与制造的物品明细。低于 1,000 时显示整数（如 `0`、`12`、`999`），从 1,000 起使用紧凑格式（如 `1.00K`、`1.25K`）。估值及缺价兜底见[物品价格模块](modules/item-prices.md#页面估值)。
- **固定一位小数**用于战斗、采集、制造的额外耗时比例（含展开的各项占比），以及采集、制造的每刻完成概率、平均单次耗时和平均单次经验，例如 `0.0%`、`2.0 秒`、`120.0`。
- **掉落期望数量**用于战斗与采集的掉落明细。`1/N` 表示展示周期内的期望数量。消耗品数量、强化收费等字段的精度与取整方式由对应页面规定。

验收覆盖双语、紧凑格式阈值和进位、负值、次数舍入、固定精度及尾零、掉落数量边界、配置零价、缺价兜底，以及同类数值在汇总和明细的一致性。
